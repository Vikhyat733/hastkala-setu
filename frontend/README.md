# HastKala Setu - Frontend Application

Modern React + TypeScript + Tailwind CSS UI for the AI-Powered Local Artisan Marketplace.

## Features
- **Artisan AI Vision Studio**: Drag & drop / camera snap upload with Gemini Vision processing, fair pricing breakdown, 8 Indian language storytelling tabs, and audio read-aloud.
- **Marketplace & GI Filtering**: Browse GI-certified handicrafts across 28 Indian states with rich storytelling, verified badges, and transparent pricing.
- **Craft Basket & Direct Tipping**: Shopping cart with customizable artisan direct tips, discount promo codes, and shipping calculator.
- **Simulated Checkout**: UPI QR code scan, card payment, and printable digital order receipts.
- **Artisan Seller Hub**: Live revenue metrics, active inventory manager, and AI Festive Demand Advisor.
- **Multilingual UI**: Native support for English, Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, and Kannada.

## Getting Started

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Run Vite Dev Server
```bash
npm run dev
```
Runs at `http://localhost:3000`

### 3. Build for Production
```bash
npm run build
```
Outputs static bundle in `frontend/dist`.
