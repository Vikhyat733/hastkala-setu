================================================================================
                    HASTKALA SETU - HOW TO START GUIDE
    AI-Powered Local Artisan E-Commerce Marketplace (SIH Mela Edition)
================================================================================

This guide explains step-by-step how to download, set up, and run both the 
Frontend and Backend on your local computer using VS Code or Antigravity IDE.

Repository URL: https://github.com/Vikhyat733/hastkala-setu.git

--------------------------------------------------------------------------------
PREREQUISITES
--------------------------------------------------------------------------------
1. Node.js (Version 18 or higher)
   Download & install from: https://nodejs.org/ (LTS version recommended)
   Verify in terminal:
     node -v
     npm -v

2. Git
   Download from: https://git-scm.com/

--------------------------------------------------------------------------------
STEP 1: DOWNLOAD / CLONE REPOSITORY TO YOUR DESKTOP
--------------------------------------------------------------------------------

OPTION A (Using Git in Terminal - Recommended):
  1. Open your Command Prompt / PowerShell / Terminal on your Desktop.
  2. Run:
       git clone https://github.com/Vikhyat733/hastkala-setu.git
  3. Navigate into the folder:
       cd hastkala-setu

OPTION B (Direct ZIP Download from GitHub):
  1. Open: https://github.com/Vikhyat733/hastkala-setu
  2. Click the green "<> Code" button -> Select "Download ZIP".
  3. Extract the ZIP folder onto your Desktop.
  4. Rename the extracted folder to "hastkala-setu".

--------------------------------------------------------------------------------
STEP 2: OPEN IN VS CODE OR ANTIGRAVITY IDE
--------------------------------------------------------------------------------
1. Open VS Code or Antigravity IDE.
2. Go to: File -> Open Folder...
3. Select the "hastkala-setu" folder on your Desktop and click "Select Folder".
4. Open the integrated terminal:
   - Shortcut: Press Ctrl + ` (backtick)
   - Or Menu: Terminal -> New Terminal

--------------------------------------------------------------------------------
STEP 3: RUN THE FRONTEND (Client Web App)
--------------------------------------------------------------------------------
In your terminal, run the following commands:

  cd frontend
  npm install
  npm run dev

Once it starts, you will see:
  VITE v5.4.21  ready in ... ms
  ➜  Local:   http://localhost:3000/

Open http://localhost:3000 in Google Chrome or any browser to view the app!

--------------------------------------------------------------------------------
STEP 4: RUN THE BACKEND (API Server)
--------------------------------------------------------------------------------
Open a NEW / SECOND terminal window in VS Code or Antigravity:
(Click the "+" icon in the top-right of the terminal panel)

Run the following commands:

  cd backend
  npm install
  npm run dev

Once it starts, you will see:
  🪔 HastKala Setu Backend Server listening on http://localhost:5000
  ✨ AI Vision & Pricing APIs ready at http://localhost:5000/api/ai

Test Health Check in browser: http://localhost:5000/api/health

--------------------------------------------------------------------------------
STEP 5: (OPTIONAL) CONFIGURE GOOGLE GEMINI VISION API KEY
--------------------------------------------------------------------------------
1. In the "backend" folder, copy `.env.example` to `.env`:
     GEMINI_API_KEY=your_actual_gemini_api_key_here
2. Or in the Frontend web app, go to "Artisan AI Vision Studio" -> click 
   "Custom Gemini Key" in the top header to enter your API key directly.
*(Note: If no API key is provided, the app runs on high-precision built-in 
smart AI neural models automatically!)*

--------------------------------------------------------------------------------
QUICK SUMMARY OF COMMANDS
--------------------------------------------------------------------------------

[ Terminal 1: Frontend ]
  cd frontend
  npm install
  npm run dev
  -> Runs on http://localhost:3000

[ Terminal 2: Backend ]
  cd backend
  npm install
  npm run dev
  -> Runs on http://localhost:5000
